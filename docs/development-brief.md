# 首期开发简报

## 目标

制作原创 PC 单机、第三人称、3D 开放世界动作 RPG。长期目标是大型商业游戏的完整度；首期冻结为一个可独立游玩 20–30 分钟的核心体验切片。优先形成真实闭环，再改善表现。所有临时素材必须明确标记并可替换，不用空按钮或假交互代替功能。

## 首期范围

- 一个小型城区和一个相连野外区域，一个可操控角色、可交互 NPC 与简单商店。
- 近战、远程、闪避、格挡和至少一个主动技能；三类普通敌人、一个精英和一个 Boss。
- 背包、装备、基础属性成长；一条主线、三条短支线、任务追踪和教程。
- 基础 UI、音效和音乐；死亡重生、存档读档和明确通关条件。
- 不做多人、MMO、塔防、MOBA、大型载具或超大城市；阵营等复杂系统留待后续。

## 技术约束

- 引擎：Godot 4.6.3 stable，项目使用 Compatibility 渲染器作为灰盒和云端无头检查的起点。
- 目标：PC；先保证当前环境可运行，再补齐目标平台导出模板和实际构建验证。
- 任务、敌人、装备和关键数值放在资源或配置中，避免集中硬编码和远期过度设计。
- 存档需要版本号、完整性校验、安全写入、备份恢复和后续迁移策略。
- 只使用免费且许可明确的资源或自制素材；记录来源、许可证和替代方案；不购买资产或调用收费服务。

## 执行顺序

干净环境验证 → 可操作灰盒 → 战斗与成长 → 城区和野外 → 敌人与 Boss → 任务和 NPC → 音画整合 → 测试与优化 → 交付。基础 UI、存档骨架和测试尽早接入。每个里程碑保留可运行构建、变更记录、测试结果、已知问题和下一步。

## 首个可玩里程碑

一个真实可操作的第三人称灰盒：角色移动和镜头、一次攻击、一个可受击敌人、基础碰撞，并有可重复的运行或无头冒烟检查。完成后再扩展内容，不用演示代码冒充系统完成。

## 首期验收

新玩家可以连续游玩 20–30 分钟，探索城区和野外，完成主线及至少两条支线，击败精英和 Boss，获得并装备物品，死亡后重生，退出后重新读档；关键状态保持一致，不复制物品、不错误推进任务、没有已知主线阻塞。必须实际运行构建、测试和游玩验证；未执行的项目明确标为未验证。
